# Neon Snake — PyCharm Edition

A polished Snake game made with Python + Pygame.

## Features

- Modern neon-style background
- Custom snake head image asset
- Smooth-looking snake segments
- Food glow effect
- Score and best score
- Pause / resume
- Restart
- WASD and arrow-key controls
- Self collision and wall collision
- Clean project structure

## Requirements

Python 3.10+ recommended.

## Run in PyCharm

1. Open the `SnakeGame_PyCharm` folder in PyCharm.
2. Open the terminal.
3. Install Pygame:

```bash
pip install -r requirements.txt
```

4. Run `main.py`.

## Controls

- Arrow keys / WASD: Move
- P: Pause
- R: Restart
- ESC: Quit
